\chapter{Open Questions and Missing Information}
\label{app:open-questions}

This appendix is a living list of gaps, unknowns, and items to verify with additional experiments.

\begin{enumerate}[leftmargin=*]
  \item \textbf{Final quantitative results (resolved):} The full evaluation suite was executed on 2026-02-19. Both the SimLingo model and the ACC baseline were tested on the 15-run test matrix (5~baseline + 10~obstacle runs). Results are reported in \Cref{ch:results}.
  \item \textbf{Compute environment (resolved for the 2025-11-26 QLabs fine-tune run):} The training machine used an \textbf{NVIDIA GeForce RTX~5070~Ti} (16~GB VRAM). \texttt{nvidia-smi} reports driver \textbf{570.195.03} and CUDA \textbf{12.8}. The Python runtime reports \texttt{torch 2.9.1+cu128} (CUDA \texttt{12.8}). The offline W\&B run also records key library versions in \path{simlingo/outputs/2025_11_26_18_06_21_qlabs_roundabout_finetune/wandb/offline-run-20251126_180635-2025_11_26_18_06_21_qlabs_roundabout_finetune/files/requirements.txt} (e.g., \texttt{pytorch-lightning==2.5.6}, \texttt{deepspeed==0.18.2}, \texttt{transformers==4.57.1}, and CUDA runtime components such as \texttt{nvidia-cuda-runtime-cu12==12.8.90}). The recorded run start time is \texttt{2025-11-26 18:06} (\path{simlingo/outputs/2025_11_26_18_06_21_qlabs_roundabout_finetune/log/git_info.txt}); the final checkpoint timestamp is \texttt{2025-11-26 23:11} (\path{simlingo/outputs/2025_11_26_18_06_21_qlabs_roundabout_finetune/checkpoints/epoch=014.ckpt}), suggesting an end-to-end wall-clock duration of approximately \textbf{5 hours}.
  \item \textbf{Camera calibration (partially resolved):} The integration encodes nominal camera intrinsics from $(W,H,\mathrm{FOV})$ and a nominal extrinsics translation via \texttt{camera\_position} in \path{core/config.py}. In the current pipeline these matrices are retained for legacy interfaces but are not consumed by the InternVL2 model path (see \path{core/camera_processor.py}), so model behavior is largely insensitive to exact calibration. If future work introduces projection-based modules (e.g., BEV geometry or depth), the QLabs camera intrinsics/extrinsics should be validated against the simulator's true camera model and sensitivity should be quantified.
  \item \textbf{Control stability:} Characterize PID gains and stability margins across speed ranges and control frequencies.
  \item \textbf{Domain generalization:} Evaluate on unseen lighting/texture variations and additional maps.
\end{enumerate}
