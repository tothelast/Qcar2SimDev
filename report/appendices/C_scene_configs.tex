\chapter{Scene Configurations}
\label{app:scene-configs}

QLabs scenarios are specified as JSON scene files under \path{config/scenes/}. Each scene references an ego route (by ID) and a list of actor IDs to spawn. Routes are defined separately under \path{config/routes/*.json}, and actor templates are stored under \path{config/actors/}.

\section{Scene schema (JSON)}
Across all scenes in this repository, the schema is minimal:
\begin{itemize}[leftmargin=*]
  \item \texttt{name}: unique scene identifier.
  \item \texttt{description}: brief human-readable summary.
  \item \texttt{\detokenize{ego_route}}: route ID used to load the waypoint route.
  \item \texttt{actors}: list of actor IDs (vehicles/pedestrians/static) to spawn.
  \item \texttt{\detokenize{actors_backup}}: optional list of fallback actors (often empty).
\end{itemize}

\section{Worked examples (described instances)}
Two representative scene files illustrate how the schema is used in practice.

\textbf{Training roundabout navigation (\path{config/scenes/training/03_roundabout_navigation.json}).}
This scene assigns \texttt{ego\_route=roundabout\_navigation} and spawns a small set of traffic-control and pedestrian actors (e.g., crosswalk and stop-sign related IDs). The purpose is to provide repeated exposure to a single, structured maneuver (entering and exiting a roundabout) with consistent environmental cues.

\textbf{Testing obstacle variant (\path{config/scenes/testing/03_roundabout_navigation_obstacle.json}).}
This scenario reuses the same \texttt{ego\_route} but changes the \texttt{actors} list to include an explicit obstacle vehicle (e.g., \texttt{obstacle\_car\_var4}). Because the route geometry is held constant, differences in outcomes can be attributed more directly to obstacle handling (stopping behavior, collision avoidance) rather than route-following variation.

\section{Related assets}
\begin{itemize}[leftmargin=*]
  \item Routes referenced by \texttt{\detokenize{ego_route}} are stored under \path{config/routes/} (e.g., \path{config/routes/roundabout_navigation.json}).
  \item Actor templates referenced by \texttt{actors} are stored under \path{config/actors/}.
\end{itemize}
