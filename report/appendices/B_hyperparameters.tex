\chapter{Hyperparameters and Configuration}
\label{app:hyperparameters}

This appendix records the most important hyperparameters and configuration choices for reproducibility.

\section{Primary configuration sources}
The repository contains multiple configuration artifacts used at different stages (experiment templates, local run configs, and saved Hydra snapshots). The three most relevant sources used in this work are:
\begin{itemize}[leftmargin=*]
  \item QLabs fine-tuning experiment (Hydra): \path{simlingo/simlingo_training/config/experiment/qlabs_finetune.yaml}.
  \item Local project-level config: \path{my_config.yaml}.
  \item Saved Hydra snapshot (used by inference loading): \path{models/simlingo/.hydra/config.yaml}.
\end{itemize}

\section{QLabs fine-tuning (Hydra experiment template)}
The Hydra experiment template in \path{simlingo/simlingo_training/config/experiment/qlabs_finetune.yaml} defines the default QLabs fine-tuning experiment, including the model backbone selection (InternVL2-1B), the LoRA adapter settings, and trainer-level defaults such as precision and distributed strategy. In practice, this file provides a reproducible baseline configuration that can be overridden by local run configs while retaining a consistent naming and logging scheme.

\section{Local run configuration (project root)}
The local project configuration in \path{my_config.yaml} captures run-specific overrides used during development (e.g., batch size/worker settings, gradient accumulation, and experiment naming). This separation (template vs. local overrides) is helpful when iterating on QLabs-specific data paths and runtime constraints while keeping the canonical experiment definition stable.

\section{Reference Hydra snapshot (SimLingo run)}
For inference reproducibility, a Hydra configuration snapshot is stored with trained model artifacts under \path{models/simlingo/.hydra/config.yaml}. This snapshot records the exact resolved configuration used during training (after all overrides), enabling later analysis of hyperparameter choices even if templates evolve.
