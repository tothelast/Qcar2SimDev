\chapter{Hyperparameters and Configuration}
\label{app:hyperparameters}

This appendix records the most important hyperparameters and configuration choices for reproducibility.

\section{Primary configuration sources}
The repository contains multiple configuration artifacts used at different stages (experiment templates, local run configs, and saved Hydra snapshots). The four most relevant sources used in this work are:
\begin{itemize}[leftmargin=*]
  \item QLabs fine-tuning experiment (Hydra): \path{simlingo/simlingo_training/config/experiment/qlabs_finetune.yaml}.
  \item Local project-level config: \path{my_config.yaml}.
  \item Resolved Hydra snapshot from the QLabs fine-tuning run: \path{simlingo/outputs/2025_11_26_18_06_21_qlabs_roundabout_finetune/.hydra/config.yaml}.
  \item Pretrained CARLA model snapshot (shipped with the pretrained checkpoint): \path{models/simlingo/.hydra/config.yaml}.
\end{itemize}

\section{QLabs fine-tuning (Hydra experiment template)}
The Hydra experiment template in \path{simlingo/simlingo_training/config/experiment/qlabs_finetune.yaml} defines the default QLabs fine-tuning experiment, including the model backbone selection (InternVL2-1B), the LoRA adapter settings, and trainer-level defaults such as precision and distributed strategy. In practice, this file provides a reproducible baseline configuration that can be overridden by local run configs while retaining a consistent naming and logging scheme.

\section{Local run configuration (project root)}
The local project configuration in \path{my_config.yaml} captures run-specific overrides used during development (e.g., batch size/worker settings, gradient accumulation, and experiment naming). This separation (template vs. local overrides) is helpful when iterating on QLabs-specific data paths and runtime constraints while keeping the canonical experiment definition stable.

\section{Resolved Hydra snapshot (QLabs fine-tuning run)}
The resolved Hydra snapshot for the QLabs fine-tuning run is stored at \path{simlingo/outputs/2025_11_26_18_06_21_qlabs_roundabout_finetune/.hydra/config.yaml}. This snapshot records the exact resolved configuration used during QLabs fine-tuning (after all overrides), enabling later analysis of hyperparameter choices even if templates evolve. The summary tables in \Cref{tab:hparams-model,tab:hparams-data,tab:hparams-trainer} are compiled from this snapshot.

\paragraph{Note on the pretrained model snapshot.}
A separate Hydra snapshot exists at \path{models/simlingo/.hydra/config.yaml}; this file records the configuration of the \emph{pretrained CARLA model} and contains different settings (e.g., \texttt{lr=3e-5}, \texttt{freeze=false}, \texttt{use\_commentary=true}). It should not be confused with the QLabs fine-tuning configuration. The corresponding pretrained checkpoint is \path{models/simlingo/checkpoints/epoch=013.ckpt} (epoch~13 of the original CARLA training run, not epoch~13 of QLabs fine-tuning); this checkpoint serves as the initialization point from which QLabs fine-tuning begins.
